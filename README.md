## 📝 Description
**বাজার দর** হলো একটি responsive ওয়েব অ্যাপ যেখানে ব্যবহারকারীরা প্রতিদিনের বাজারদর দেখতে পারবেন।  
এখানে পণ্যের দাম, দাম বাড়া‑কমার ট্রেন্ড, ক্যাটাগরি অনুযায়ী ফিল্টার, এবং প্রোডাক্ট ডিটেইলস পেজ রয়েছে।  
Authentication সিস্টেম ব্যবহার করে নির্দিষ্ট route (যেমন Product Details, Profile Update) protect করা হয়েছে।  

---

## 🛠️ Technologies Used
- **Next.js (App Router)** → UI এবং Routing
- **Tailwind CSS + DaisyUI** → Styling এবং Responsive Design
- **TypeScript** → Type Safety
- **BetterAuth** → Authentication (Email/Password + Google/GitHub)
- **React Hot Toast** → Notifications
- **Vercel** → Deployment

---

## ✨ Key Features
1. 🔝 **Navbar** — Logo, Bangla Date, Category Links, Auth Buttons, Price Ticker  
2. 🅱️ **Hero Banner** — Heading, Subtitle, CTA Button, Banner Image  
3. ⚖️ **Product Sections** — Top Risers, Top Fallers, All Products Grid  
4. 📄 **Product Details Page** — Protected route, Summary, Price Stats, Market‑wise data  
5. 🗂️ **Category Page** — Sort dropdown, Loading skeleton, Empty state  
6. 🔐 **Authentication** — Sign In/Sign Up with BetterAuth + Social Login  
7. 🛠️ **Profile Update** — User info update form (BetterAuth API)  
8. 📱 **Responsive Design** — Mobile, Tablet, Desktop friendly  
9. ❌ **404 Page** — Friendly error page with CTA back to Home  
10. ⏳ **Loading Animation** — Skeleton + Custom animated loader
